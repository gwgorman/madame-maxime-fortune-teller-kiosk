# JERRAY wireless DMX kit - ASIN B0CKX7WRRR

This is the planned wireless transport layer for distributing one DMX512
universe around the house and yard. It is not a separate controller and does
not assign fixture addresses.

## Listing identification

- Brand: JERRAY
- Amazon ASIN: `B0CKX7WRRR`
- Package: one transmitter, seven female receivers, and seven power adapters
- Connector: 3-pin DMX
- Radio: 2.4 GHz ISM, GFSK modulation
- Frequency behavior: listing claims automatic hopping across 126 channels
- Pairing: seven selectable, color-indicated ID groups
- Power: listing says the receivers have no internal batteries and require the
  supplied adapters
- Claimed range: up to 400 m line of sight; this is a seller claim and must not
  be treated as verified performance around the house, trees, guests, or other
  2.4 GHz equipment

Source listing: <https://www.amazon.com/dp/B0CKX7WRRR>

All specifications remain provisional until the delivered units and included
instructions are inspected.

## Planned topology

```text
Raspberry Pi
  -> ENTTEC Open DMX USB
  -> JERRAY transmitter
  ~~ 2.4 GHz wireless DMX ~~
  -> receiver(s)
  -> local fixture or short wired DMX chain
```

Every receiver repeats the same DMX universe. Fixture addresses, not wireless
ID groups, determine which channels each light or laser obeys. Use one shared
wireless ID group for the normal single-universe installation. The remaining ID
groups are independent radio networks, not additional universes generated by
the current Pi controller.

## Bring-up sequence

1. Inspect every transmitter, receiver, adapter, connector, and instruction
   sheet; record labels and input-voltage requirements.
2. Keep lasers physically disconnected. Connect the transmitter to the ENTTEC
   and one receiver to one PAR fixture.
3. Select the same ID color on the transmitter and receiver. Verify steady
   static colors and smooth fades before adding another receiver.
4. Test every receiver individually with the forgiving PAR load, then test all
   receivers together at their intended locations.
5. Measure behavior when DMX input stops, transmitter power is removed,
   receiver power is cycled, RF is obstructed, and the Pi application exits.
6. A receiver that freezes its last frame is not a laser safety device. Laser
   interlocks, shutters, physical termination, and local zero-output behavior
   remain mandatory.
7. Test coexistence with the property's Wi-Fi and other 2.4 GHz devices under
   realistic party traffic.
8. Only after those tests, connect one laser at a time with its master/output
   channel held in the documented off range.

## Driver implication

The current Open DMX driver transmits 64 channels to maximize timing margin for
the PAR-only installation. The provisional laser addresses require at least 72
channels. Raise the transmitted frame to 96 channels only when laser support
is implemented, then repeat the long idle-flicker test through the wireless
link before any optical output is enabled.
